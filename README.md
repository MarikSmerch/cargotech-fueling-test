# Заправка в рейсе — CargoTech

Тестовое задание: прототип мобильного сценария безналичной заправки для водителя грузовика. 

## Статус

В репозитории размещены исходные материалы задания и стартовый каркас приложения. **Полный сценарий заправки пока не реализован.**

## Структура

- `index.html` — стартовая HTML-страница; в дальнейшем — весь интерфейс.
- `app.js` — логика приложения на чистом JavaScript.
- `fake-api.js` — предоставленный заказчиком браузерный API (без изменений).
- `materials/maket.html` — исходный макет первого и последнего экранов.
- `materials/Задание - Заправка в рейсе.pdf` — исходное ТЗ.
- `materials/Разговор с диспетчером.docx` — разговор с водителем.
- `materials/Вопросы по кейсу.docx` — пустой шаблон анкеты, предоставленный заказчиком.

## Запуск

Откройте `index.html` в браузере. Для локального HTTP-сервера также можно выполнить:

```bash
python -m http.server 8000
```

Затем перейти на `http://localhost:8000`.

Никаких фреймворков, внешних библиотек, сборки или backend-сервера не требуется.

## Требования

- Рабочий сценарий от главного экрана до результата заправки.
- Корректная обработка обрывов связи, повторных запросов, отмены и ошибок API.
- Приложение в `index.html` и `app.js` не более 60 КБ суммарно (`fake-api.js` не входит).
- Осмысленная история Git-коммитов.

## Расхождения между материалами

_Будет заполнено после отдельного анализа макета, API и разговора с диспетчером. Для каждого расхождения будет указано принятое решение и его обоснование._

## Решение для владельца парка

_Будет добавлено: одна выбранная мера (до 10 строк), две отвергнутые альтернативы и метрика проверки результата через месяц._

## Примечание

Исходные материалы сохранены отдельно, чтобы не смешивать их с разработкой. Заполненный документ с ответами на вопросы предыдущего кейса будет отправлен заказчику отдельно по электронной почте, а не опубликован в этом репозитории.
